LBrixx Brickmo V15

1. app.py und requirements.txt im GitHub-Repository lbrixx-pricecrawler ersetzen.
2. Auf Streamlit-Neustart warten.
3. Produkt auswählen oder 'Eigene URL' wählen und Link einfügen.
4. 'Brickmo-Preis prüfen' klicken.

Hinweis: Verfügbarkeit und Versandkosten sind noch nicht abschließend automatisiert. Preise aus Shops können von dieser HTML-Extraktion abweichen.
